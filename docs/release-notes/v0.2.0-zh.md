## Jcc Switch v0.2.0

### 新功能

- 一键录入支持更多应用：确认页新增「更多应用」，可以把同一个 Key 一起写进 Claude Desktop、OpenCode、OpenClaw、Hermes、Pi、Oh My Pi、MiniMax Code、DeepSeek Harness、Kimi Code 和 Grok Build。默认不勾选，只列出侧栏里开着的应用。
  - Claude 系模型走 Anthropic 协议，其它模型走 OpenAI 兼容协议；官方供应商（如 DeepSeek、Kimi、智谱）会沿用该应用里的同名预设。
  - Claude Desktop 沿用 Claude Code 的模型；模型不是 Claude 系时需要开启本地代理。
  - Grok Build 只在模型列表里有 Grok 模型、且中转站支持 Responses 接口时可选。检测用空请求，不会调用模型、不产生费用。
