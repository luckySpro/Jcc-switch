## Jcc Switch v4.1.0

Jcc Switch 基于 CC Switch v4.0.21，这是第一个独立版本。

### 新增

- **粘贴 Key 一键配置**：首页点「粘贴 Key」，或在主界面空白处按 Ctrl/⌘+V。支持裸 Key、环境变量、JSON、curl 命令和「地址 + Key」。会自动识别供应商（内置 16 家规则），只向候选供应商的官方域名请求模型列表，再按名称给 Claude Code 的四个模型槽位、Codex 和 Gemini CLI 分配模型，确认后写入配置。
- **中转站**：粘贴内容里带 http(s) 地址时，按兼容接口配置：Claude Code 用根地址，Codex 用 `/v1`。粘贴开头的标题行（如「gpt官转：」）会用作供应商名称。
- **色卡**：设置 → 通用，可选陶土（默认）、石墨、青瓷、靛蓝、绯红，或 CC Switch 原版配色。

### 变化

- 数据目录改为 `~/.jcc-switch`。首次启动时从 `~/.cc-switch` 复制数据库和设置，可以和 CC Switch 同时安装。
- 应用标识改为 `com.mjgroup.jccswitch`。

### 已知限制

- 安装包暂未签名，应用内自动更新暂不可用。
- 识别规则还没有逐家用真实 Key 验证过。
